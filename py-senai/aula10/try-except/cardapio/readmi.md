# 🍔 Sistema de Pedidos - MCFritas

## 📖 Sobre o Projeto

Este projeto simula um sistema simples de pedidos para uma lanchonete fictícia chamada **MCFritas**.

O programa apresenta um cardápio ao usuário, recebe a escolha de um item e realiza validações para garantir que a entrada seja válida.

O principal objetivo deste exercício é praticar o uso de **tratamento de exceções em Python**, tornando a aplicação mais segura e resistente a erros de entrada.

---

## 🚀 Funcionalidades

* Exibição do cardápio
* Seleção de itens pelo número correspondente
* Validação de entradas inválidas
* Tratamento de erros utilizando exceções
* Confirmação do pedido realizado

---

## 🛠️ Tecnologias Utilizadas

* Python 3
